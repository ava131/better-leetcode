# prompt 备份

**改 `../system.md` 之前，先把当前这一版复制进来**，命名 `system.v<版本>.md`。

理由：prompt 是这套产品里最该被当作"代码"对待的东西 —— 一次措辞改动会直接改变
回答风格，而且很难回滚验证（同一个问题问两次，模型给的答案都不一样）。
git 里有历史，但放在这里能一眼看到"上一版长什么样"，不用翻 commit。

| 版本 | 文件 | 说明 |
|---|---|---|
| v0.8.0 | `system.v0.8.0.md` | 加「未提交状态不要贴完整代码」之前的那一版（104 行） |
| v0.8.1 | `system.v0.8.1.md` | 加「`<cursor>` 光标块」之前的那一版（138 行，就是从 v0.8.0 改出来的那版） |

> v0.8.1 那次我**先改了才想起备份**，所以是从 git 里取的（`git show HEAD:...`）。
> 别学这个 —— 先 `cp` 再改。
